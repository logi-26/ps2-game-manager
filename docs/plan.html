Where it stands

Part 1 is built and verified end to end. The server compiles from source on the installed JDK, boots, and answers all of its protocol commands; the desktop app compiles (48 sources → 298 classes), launches against a local server, and keeps its file churn out of the repo. What remains in Part 1 is an interactive click-through and a couple of decisions.

Toolchain
Temurin JDK 25.0.1 only — no 8/11, no Ant, no NetBeans. Builds target --release 11. Python 3.11 (has Pillow) + 3.14.
Repo
Consolidated into github.com/logi-26/ps2-game-manager with desktop/ + server/ dirs. The three old repos (oplpops-*) are kept for history.
Backend
oplpops-server — raw TCP on 6789, length-prefixed binary protocol, serves static files from folders beside its own jar. oplpops-api is an abandoned stub.
Not in scope
MyFTPClient talks to a real PS2 console over FTP — unchanged. MyAPIClient is empty — it gets filled in during Part 2.

Decision

One fresh repo, not three

The overhaul’s core change — swapping the TCP protocol for the HTTP API — touches the API and its one client together, so they belong in one commit history. The current repos hold almost no history worth preserving, and the rename is a clean cut-over point. Archive the three GitHub repos read-only and link them from the new README; keep the old server in-tree as reference until it’s retired.

Known rough edges

Carried forward, not yet fixed:

  • Swing on JDK 25 / Win10 looks dated; HiDPI scaling may be off. Not blocking.
  • sevenzipjbinding native load can fail on modern Windows → archive extraction breaks, app still starts.
  • server/ has no auth, path sanitisation, or connection limits (only matters if it's ever exposed beyond localhost, and it's on its way out regardless).
  • java.net.http.HttpClient defaults to an HTTP/2 upgrade attempt on every request; uvicorn's dev server mishandles it and silently drops POST bodies. MyApiClient pins HTTP_1_1 — worth re-checking if the API ever moves behind a real HTTP/2-capable proxy.
  • Don't run two OPLPOPS instances (old or new) at once — they fight over the same sevenzipjbinding native-library temp folder, and the loser's PS2 game-ID detection fails silently.
