Version 0.6 (Beta)  -  06 January 2018
    * Improved the cheat display algorithm.
    * Improved the file report screen (the current console and selected gameID are automatically inserted).
    * Improved the share VMC screen (the current console and selected gameID are automatically inserted).
    * Improved some other bits of code.
    * Fixed a bug were the PS1 game directories were not being named with the game ID.
    * Changed the PS1 game list to be ordered alphabeticaly.
    * Changed the CFG-DEV folder back to CFG.
    * Changed the conf_elm.cfg to conf_apps.cfg.
    * Added the ability to batch upload PS1 games in HDD mode (over network).
    * Added the ability to batch upload PS2 games in HDD mode (over network).
    * Added the ability to read a ul.cfg file.
    * Added a feature to generate a ul.cfg file.
    * Added the ability to convert PS2 games to UL format.
    * Added the ability to convert PS2 games from UL format back to ISO format.
    * Added a feature to highlight UL format games in the game list.
    * Added the ability to generate PS1 spine ART for all PS1 games.
    * Added the ability to delete all PS1 spine ART from the ART folder.
    * Added the ability to store any invalid games so that the user is not notified about any specific game more than once.
